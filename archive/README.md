# Archive

`Unlimited_OCR_original.ipynb` is the first version of this project: a single
Google Colab T4 notebook with outputs and widget state from a real run.

It is kept for reference and for anyone who wants to see the original
end-to-end flow. New users should use the maintained notebooks in
[`../notebooks/`](../notebooks/):

- `Unlimited_OCR_Colab_T4.ipynb`
- `Unlimited_OCR_Colab_L4_A100.ipynb`
- `Unlimited_OCR_Local_GPU.ipynb`
- `Unlimited_OCR_Local_CPU.ipynb`
- `Unlimited_OCR_Apple_Silicon.ipynb`
- `Unlimited_OCR_SGLang_Server.ipynb`

The original notebook contains saved outputs (including a sample invoice) and
Jupyter widget state. The maintained notebooks are generated without outputs so
they stay small and diff-friendly.
